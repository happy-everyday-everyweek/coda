## 1. 通用判定

- 每项必须记录 commit、环境、精确版本、命令、结果和日志位置；`PASS` 必须可重放。
- `IMPLEMENTED`、`TESTED-MOCK`、`CI-GREEN`、`EXPERIMENTAL`、`BLOCKED` 都不是发布 `PASS`。
- 真实 Agent 验收必须用真实服务和真实工具循环；mock LLM 只覆盖协议/进程路径。
- Android 跨端验收必须至少一台真 Android 设备和一台真实桌面；模拟器/假节点只能补充。
- 每阶段 Gate 中任何必需项 `FAIL/BLOCKED/NOT RUN`，Gate 不通过。
- 第一阶段与第二阶段不得同时声称同一数据目录有两个写权威。
